# Mudra goes to Bagan

Claymation / Aardman-inspired junior story book in the **Mudra goes to…** series.

## Arc

1. Mudra Goes to Bagan — Intro (bus dawn)
2. Rooster Alarm — Character (guest house)
3. Nyaung-U Market — Rising
4. Hot Temple Steps — Rising
5. Bicycle Bounce — Belonging
6. Balloon Scare — Challenge
7. Irrawaddy Splash — Friendship
8. Quiet at Shwezigon — Quiet climax
9. Thousand Temples Sunset — Peak & ending

## Structure

Same as `Mudra holiday trip to Myanmar`:
- 001 briefing → 002 contents → 003 character
- 9 chapters × (words page / sentences page / hear-MM quiz)
- 031 congrats
- 3 image+story+practice blocks per words/sentences page

## Character lock

- **Mudra**: age 7, fair, cute, short black hair, pink hair clip shaped like letter **M**, no thanaka
- Distinct adult faces: Grandma ≠ Auntie Hla ≠ Mother; Father ≠ Uncle/Ko Ko adults
- Style: stop-motion claymation / Aardman (sculpted clay, fingerprints, warm soft lighting)

## Generate

```bash
node _generate-book.cjs
```
