# Global Warming — Book Structure Guide

**Author:** Jimmy Cooper  
**Target age:** 7–8  
**Chapters:** 35 standalone HTML files  

Follows the same flow as **Ocean Adventure** (reference: [../OceanAdventure/README.md](../OceanAdventure/README.md)), with painted PNG scenes embedded in each HTML file (Solar System / Dinosaur Discovery data-URI pattern — no external image fetch).

Master template: [../README.md](../README.md)

---

## Page structure (2026 refresh)

### Activity pages (`008`, `011`, … + overview `005`)

Each topic activity follows:

**picture → story → explanation → press words to hear** (×3) → **mini-game**

| Block | What it shows |
|-------|----------------|
| **Picture** | 16:9 painted PNG scene (`<img class="chapter-hero-img">` from embedded data URI) |
| **Story** | Maya + Professor Leaf narrative in `.story-box` |
| **Explanation** | Factual summary in `.explain-box` |
| **Press words to hear** | `.speak-chip` buttons → `GlobalSpeak.chip()` (Web Speech API) |
| **Mini-game** | Canvas game via `GlobalGame.boot()` at bottom |

### Explained pages (`006`, `009`, …)

**picture → story → explanation** (×3) — deeper content, no vocabulary chips, no game.

### Quiz pages (`007`, `010`, …)

VS bar + 5 questions + podium finish. Uses `GlobalPlayer` for name/avatar.

### Overview (`005-Climate-Overview.html`)

**Hand-maintained** — not regenerated by `_generate-book.cjs`. Four interactive canvas views (Earth layers, heat map, weather patterns, atmosphere) plus Climate Sort mini-game.

## Design concept

| Principle | Implementation |
|-----------|----------------|
| Theme | Earth-green gradient, `.leaves` animated background |
| Accents | Green `#81c784`, light green `#a5d6a7`, gold `#ffeb3b` |
| Background | `linear-gradient(180deg,#1a2e1a 0%,#2d5016 50%,#1b4332 100%)` |
| Borders | `rgba(129,199,132,...)` |
| Default hero | 🌍 Eco Hero |
| localStorage key | `book:globalwarming:*` |
| Illustrations | **Quality PNG** embedded as base64 in `_global-chapter-images.js` |
| Vocabulary | **Press words to hear** via `_global-speak.js` |
| Structure | One standalone HTML file per chapter |
| Learning loop | Activity → Explained → Quiz (×9 topics including overview) |

## Shared files

```
GlobalWarming/
  _global-data.js                # Chapter stories, words, quiz Q&A, game configs
  _global-chapter-images.js      # Embedded PNG scenes (generated)
  _global-scenes.js              # GlobalScene.boot() — injects <img> into scene slots
  _global-speak.js               # GlobalSpeak — press words to hear (TTS)
  _global-player.js              # GlobalPlayer localStorage helper
  _global-games.js               # Shared minigame engine
  _generate-book.cjs             # Regenerate activity / explained / quiz HTML
  _gen-index-grid.cjs            # Refresh index chapter grid
  scripts/
    sync_ai_images.cjs           # Copy AI chapter PNGs into assets/
    gen_chapter_images.cjs       # PNG → _global-chapter-images.js
  assets/                        # Source PNGs ({chapter-id}-{slot}.png)
  *.html                         # Standalone chapters
```

### Build pipeline

```bash
# 1. Place / sync quality chapter PNGs
node book_html/GlobalWarming/scripts/sync_ai_images.cjs

# 2. Embed all PNGs as data URIs (single-file, no fetch)
node book_html/GlobalWarming/scripts/gen_chapter_images.cjs

# 3. Regenerate activity, explained, and quiz HTML from _global-data.js
node book_html/GlobalWarming/_generate-book.cjs

# 4. Refresh index grid
node book_html/GlobalWarming/_gen-index-grid.cjs
```

Replace a hero illustration: update PNG in `assets/`, re-run steps 2–3.

**Chapter art (54 images):** overview, greenhouse, carbon-dioxide, fossil-fuels, renewable-energy, melting-ice, rising-seas, wildlife, green-future — each has 6 slots (`main-1`…`main-3`, `explain-1`…`explain-3`).
